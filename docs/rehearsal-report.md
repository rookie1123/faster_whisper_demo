## 离线彩排

为避免关闭整台电脑网卡导致协作会话中断，本次使用进程级网络封锁：Python 启动时把 DNS 查询与 socket 连接全部改为立即报错，并同时设置 `HF_HUB_OFFLINE=1`、`TRANSFORMERS_OFFLINE=1`。终端打印 `OFFLINE_GUARD_ACTIVE=1` 后才开始转写，因此该 Python 进程无法访问网络。
